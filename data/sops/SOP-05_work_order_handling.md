# SOP-05 Work Order Handling

## 5.1 Work order ID format

Every part carries the ID of its work order, stamped on the part. The ID is the letters WO, a hyphen, and five digits, for example WO-48213. An ID in any other form is not valid and must not be entered.

## 5.2 Work order statuses

A work order has one of these statuses: open, in inspection, on hold, in rework, closed, or scrapped. Only a work order that is open or in inspection may receive new inspection results.

## 5.3 Placing a work order on hold

Place the work order on hold as soon as a defect needs a decision from someone else. Parts from a work order on hold stay at the inspection station and do not move to the next operation. Only the Shift Supervisor may release a hold.

## 5.4 Recording defects

Record every defect against its work order in the ERP system during the same shift in which it was found. Record the defect type, the measured value and the disposition. Paper travelers are not an accepted record.

## 5.5 Mismatched ID

If the ID stamped on the part does not match the work order on the traveler, do not continue. Place both work orders on hold and escalate to the Shift Supervisor, because parts may have been mixed between orders.

## 5.6 Closing a work order

A work order is closed only when every part has a disposition: accepted, reworked and re-inspected, or scrapped with approval. A work order with a part still on hold cannot be closed.
